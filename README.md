# 云邮 (CloudMail) 📧

> 作者：罗根

一款从零编写的 Android 多账号邮箱客户端（Kotlin + Jetpack Compose），使用真实 IMAP/SMTP 协议收发邮件，无任何模拟功能。当前版本 v1.3.x。

## 功能总览

| 分类 | 功能 |
|---|---|
| 账号 | 多账号添加（QQ / 163 / 139 / Outlook / Gmail / 自定义任意邮箱），密码或授权码登录，验证后自动预填服务器信息，自定义昵称与头像，设主邮箱（默认发信账号），删除账号（回首页自动切到全部邮件），编辑账号 |
| 聊天模式 | 首页一键进入：邮件按联系人自动生成聊天会话列表（头像/最后一条消息预览/未读数/时间），聊天页对方邮件靠左气泡、我的靠右气泡（账号头像/联系人首字圆标），点气泡查看完整邮件详情，进入聊天自动标记已读，底部输入框直接发消息——底层仍是真实 IMAP/SMTP 邮件，无需自建服务器，对方用 QQ/163 等任何邮箱都能正常收发，随时切回传统邮件界面 |
| 收件 | IMAP 真实收信 + IMAP IDLE 实时推送（毫秒级，轮询只做备用），新邮件系统通知（显示发件人/内容，可点开、可删除），全部邮件聚合、未读、星标、草稿/待发送、回收站、广告邮件自动识别标注 |
| 发件 | SMTP 真实发信（3 次重试），多收件人、抄送、密送、主题、图片/任意文件/录音附件（支持现场录音），名片(资料卡)与纯文本两种发信模式，已读回执，定时发送（到点真实触发，APP 被清理也生效），收到他人 vCard 名片自动渲染成完整资料卡（头像/电话/单位/地址） |
| 待发送 | 草稿与定时邮件统一列表，可继续编辑、立即发送、取消定时；发送状态条实时显示，草稿在删除账号后仍保留 |
| 已发送 | 所有发过的邮件（含所用账号、收件人、附件），可撤回、删除、再次编辑 |
| 撤回 | 删除服务器上原邮件 + 向收件人发送撤回通知（协议内最大能力，详见下方说明） |
| 附件 | 附件预览/保存到下载文件夹，图片大图预览，视频/音频/其他文件调用系统播放器打开 |
| 联系人 | 自动识别来信人并一键添加，备注名/电话/单位/备注，重要联系人（来信通知明确标注），三种排序，备注优先显示，点联系人直接发信，删除联系人 |
| 正文 | HTML 邮件完整渲染（含内联图片位置还原）、cid 内联图片显示、纯文本自动排版、链接自动高亮（含真实域名校验）、插入链接邮件、字体与字色、卡片模板（8 种样式实时预览）、阅读位置保留（点图片/浏览器返回不回顶）、WebView 渲染崩溃自动恢复 |
| 可靠性 | 半死连接自动重建（网络波动重试无效的问题已修）、收件毫秒级实时化、搜索状态/阅读位置/列表位置全局保留、系统清后台后重开自动全屏（同时保留右上角滑动小窗能力）、名片头像 PNG 一次性渲染不闪屏 |
| 其他 | 长按/详情删除/恢复/彻底删除/清空回收站、全局搜索（邮件+联系人）、回复、星标、置顶、往来邮件视图、排序模式 |

## 撤回与已读回执的真实限制（重要说明）

邮件协议（SMTP/IMAP）本身不支持“从对方收件箱移除邮件”，QQ 邮箱网页版的撤回是腾讯私有接口，第三方客户端无法调用。因此本 App 的撤回是协议内能做到的真实操作：

1. **从你自己的服务器「已发送」文件夹删除原邮件**（服务器级真实删除）；
2. **向收件人真实发送一封「邮件撤回」通知邮件**（与 QQ 内部撤回提示体验一致）；
3. 同一服务商之间（如 QQ→QQ、163→163），服务商网页版可能支持彻底撤回，App 会如实提示。

已读回执通过标准 `Disposition-Notification-To` 头实现，同域邮箱支持较好，跨域邮箱无法保证——这是协议现实，不是 Bug。

## 聊天模式说明

聊天不是“伪装”：底层每一“条消息”就是一封真实邮件（对方收到的就是普通邮件，可用任何邮件客户端查看）。会话按对方邮箱地址自动分组，同一个人的多封往来邮件合并显示。发消息时主题自动取消息首行，方便对方在邮件客户端里识别。

## 如何添加邮箱账号（QQ 邮箱示例）

1. 电脑登录 QQ 邮箱网页版 → 设置 → 账户 → 开启「IMAP/SMTP 服务」；
2. 按提示发送短信生成**授权码**；
3. 在云邮「添加邮箱账号」中选择 QQ邮箱 → 填邮箱地址 → **密码填授权码** → 验证并登录。

163 / 139 / Outlook / Gmail 同理：先在服务商设置里开启 IMAP 并生成授权码/应用专用密码。

## 用 GitHub 云端编译 APK（图文步骤）

本仓库已内置 GitHub Actions 编译流水线（`.github/workflows/build.yml`），推上去即自动编译。

1. **生成新令牌**：GitHub → 右上角头像 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token，勾选仓库的 **Contents: Read and write**、**Actions: Read** 权限（⚠️ 不要把令牌发给任何人/聊天）。
2. **创建仓库**：GitHub → New repository，名称如 `CloudMail`，Public 或 Private 均可。
3. **上传源码**（本 zip 解压后）：
   ```bash
   cd CloudMail
   git init
   git add .
   git commit -m "init"
   git branch -M main
   git remote add origin https://github.com/你的用户名/CloudMail.git
   git push -u origin main
   ```
4. **Actions 自动编译**：推送后进入 Actions 页，等待 Build APK 完成，在 Artifacts 里下载 APK 安装。
